# Timeline

Two building blocks for telling a career:

- **`TimelineAxis`**: a time-scaled line with a tick per year, a span per company and a dot per role. Give it `activeIndex` and it fills up to that company, so a page can move through the career one chapter at a time.
- **`TimelineChapter`**: one company's story: period, company, a chapter line, the roles held, one line of work and the stack that defined it.

## Use when

- Order and pace matter: the axis shows how long each period lasted and how quickly roles changed.
- Each period fits a chapter line, its roles, one line of summary and a few tags.

## Don't use when

- Entries need bullets, links or long descriptions: use `Card`s.
- Order doesn't matter: use a plain list.

## Data

- Entries are oldest first, with `start` / `end` as `"YYYY-MM"` and each role's `start`.
- The axis runs from January of the first year to the last `end`. Positions come from `timelineScale.ts` (pure, unit-tested) and reach the styles as CSS variables (`--at`, `--from`, `--to`, `--fill`); each span and dot carries `data-state="past | current | future"`.

## Accessibility

- The axis is decorative (`aria-hidden`): nothing it shows is missing from the chapters, so no information depends on position or color.
- Each chapter is an `<article>` with a heading (`headingLevel`, default `h3`), an ordered list "Roles at …" and a list "Stack at …"; the → arrows are hidden from screen readers.
- The axis is hidden below `md`, where chapters stack with a side rule and a marker.
- Fill and dot transitions are disabled under reduced motion (`motion-reduce:transition-none`).
- Colors come from semantic tokens (`accent`, `line`, `muted`, `bg` for the dot ring) rather than component tokens: the axis has none of its own.

## Do / Don't

| Do                                           | Don't                              |
| -------------------------------------------- | ---------------------------------- |
| One chapter per company; promotions as roles | One chapter per promotion          |
| A chapter line that says what changed        | Repeating the job title as chapter |
| Three or four tags that defined the period   | The full CV skills list            |
