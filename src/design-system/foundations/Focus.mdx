# Focus

One keyboard focus ring for every interactive element: 2 px, offset 3 px, in the focus color.

## Use when

- Every new interactive element: add `focusRing` from `ui/focus.style.ts`.
- A wrapper around a hidden input: `focusRingWithin`.

## Don't use when

- `outline-none` without a replacement.
- A different ring per component.

## Accessibility

- The ring is 3:1 or better against `bg` and `surface` (WCAG 1.4.11) and appears for keyboard focus only (`:focus-visible`).
- The 3 px offset keeps it visible on filled and outlined elements alike.
- Never remove it to tidy a design: keyboard visitors have no other way to see where they are.

## Do / Don't

| Do                       | Don't                       |

| `focusRing` from the kit | Copying the outline classes |
