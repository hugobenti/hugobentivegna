# Button

An action the visitor can take. Renders a native `<button>`, or an `<a>` when it navigates.

<Canvas of={Stories.Default} />
<Controls />

## Use when

- The visitor triggers an action (`<button>`): copy, switch, replay.
- The visitor goes somewhere or downloads something (`href` makes it an `<a>`): contact, live demo, CV.

## Don't use when

- The text is part of a sentence: use a plain link.
- The element only labels something: use `Tag`.
- You need more than one `primary` in the same view: demote the others to `secondary` or `ghost`.

## Accessibility

- Without `href` it is a `<button type="button">`, so it never submits a form by accident.
- With `href` it is a real link: middle-click, "open in new tab" and the browser status bar all work.
- `external` adds `target="_blank"`, `rel="noopener noreferrer"`, a visual ↗ and the hidden text "(opens in a new tab)".
- The focus ring uses the `focus-ring` component tokens and meets 3:1 contrast.
- Sizes: `sm` is 32 px high, for compact controls such as PlaybackControl; `md` is 40 px and `lg` 48 px. Every target is at least 24 px (WCAG 2.5.8).
- Disabled applies to the native `<button>` only: it dims the button, removes it from the tab order and ignores clicks. A link (`href`) has no disabled state and the prop is not accepted: when an action isn't available, render a disabled `<button>` or leave the link out. Don't fake it with `pointer-events` or `aria-disabled`, which keep a dead link focusable.
- Hover only changes color or brightness: it never carries information, so touch and keyboard users miss nothing.
- The label is the accessible name. Icon-only buttons are not supported: always pass text.

## Do / Don't

| Do                                      | Don't                               |
| --------------------------------------- | ----------------------------------- |
| `href` for anything that navigates      | `onClick={() => location.href = …}` |
| One `primary` per view                  | Several competing `primary` buttons |
| Short verb-first labels ("Download CV") | Vague labels ("Click here")         |
